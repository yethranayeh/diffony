How Zinn sounds

The Chandra X-ray Center turns telescope images into sound by sweeping a line across them. Whatever the line crosses becomes a note. These plates do the same with Zinn's own records: measured command timings, a full test run, and the git history.

Each plate has two sounds. Raw data plays every event exactly when and how it happened. Arranged plays the same events, but lets the data decide only when a note plays, how loud, and on which instrument, while a fixed key and chord loop decide which notes are allowed. Switch between them to hear the difference, and mute layers to hear what each one adds. Headphones help with the low notes.

A command run

The timing harness ran each command 30 times. Replayed at real speed, every run is one beat, so each command has a tempo. Speed the replay up past about 20 beats a second and the beats fuse into a note. Faster commands sound higher, and two commands' speed ratio is the musical interval between them.

    Test files run one after another, so each file starts where the previous one ended. Inside a file, tests are laid out in order and scaled to the file's time, so their positions within a file are approximate.

    Arranged mode is in D major and loops four chords, one per bar: D major 9 (I), B minor 9 (vi), G major 9 (IV) and A add 9 (V). Every instrument is synthesized in the page, and the room sound is a generated reverb.
